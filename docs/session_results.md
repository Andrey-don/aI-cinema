#### Фаза 3 — Инфраструктурные файлы

**`production/status.md`** — трекер состояния производства:
- Секция А: 31 строка — все кадры датасета Человека (M1–M2, R1–R7, P1–P2, E1–E6, O1–O5, D1–D9)
- Секция Б: 23 строки — все кадры датасета Собаки (S1–S2, SR1–SR7, SP1–SP2, SE1–SE5, SO1–SO3, SD1–SD4)
- Секция В: 8 строк — статус раскадровки / изображения / видео по каждой сцене

**`assets/registry.md`** — реестр всех сгенерированных ресурсов:
- 4 референсных листа уже заполнены со статусом `✅ approved`
- Строки для 2 мастер-кадров Человека, 2 мастер-кадров Собаки, 8 сцен (изображения), 8 видеоклипов

**`production/transitions.md`** — протокол last-frame → start-image:
- 7 строк для всех переходов между сценами
- Инструкция: скачивать в 2K, сохранять как `scene_NN_last_frame.jpeg`, заполнять обе колонки

#### Фаза 4 — Агентные инструкции (папка `agents/`)

**`agents/00_orchestrator.md`** — Оркестратор:
- Полная схема пайплайна (от разработки идеи до монтажа)
- Карта всех файлов системы
- Инструкция запуска агента в новый чат (скрипт для копирования)
- Таблица инструментов по этапам
- Текущий статус производства «Костра»

**`agents/00_developer.md`** — Девелопер:
- 9-шаговый алгоритм генерации идеи
- Читает `_knowledge_base/guides/idea_algorithm.md`
- Пишет: synopsis.md, CLAUDE.md фильма, profiles персонажей

**`agents/01_storyboarder.md`** — Раскадровщик:
- Читает: script/ + characters/
- Пишет: storyboard/scenes/scene_NN.md (8 файлов)
- Формат 3-слойного файла сцены (литературный / режиссёрский / технический)
- Правило завершения: обновить status.md

**`agents/02_frame_generator.md`** — Генератор кадров:
- Читает: storyboard/ + characters/ + registry.md
- Пишет: registry.md (строки SC01–SC08) + status.md
- Правила: Character Lock, 2K download, одобрение пользователем

**`agents/03_videographer.md`** — Видеограф:
- Читает: registry.md (approved) + transitions.md + storyboard/
- Пишет: video_prompts.md + transitions.md + registry.md (VID01–VID08)
- Last-frame правило: без заполненного transitions.md не запускать следующую сцену

**`agents/04_editor.md`** — Монтажёр:
- Читает: registry.md (видео) + transitions.md + music_prompts.md
- Пишет: `production/edit_plan.md`
- Формат: таблица клипов, музыкальные метки, тайм-коды, чеклист рендера

#### Фаза 5 — Раскадровка 8 сцен (`storyboard/scenes/`)

Создано 8 файлов. Каждый содержит три слоя:

| Сцена | Название | Тип кадра | Ключевой образ |
|-------|----------|-----------|----------------|
| scene_01.md | Начало пути | Extreme wide shot | Человек = точка в бесконечной пустыне |
| scene_02.md | Человек и Собака | Medium tracking | Дистанция между ними = психологическая пропасть |
| scene_03.md | Провал под лёд | Medium static | Собака отступила до того, как он провалился |
| scene_04.md | Первый костёр | Medium push in | Ветви со снегом нависают над головой (он не смотрит вверх) |
| scene_05.md | Снег гасит костёр | Slow motion | #E8A020 → #C8D8E8 за одну секунду |
| scene_06.md | Борьба со спичками | Extreme close up | Руки не слушаются |
| scene_07.md | Принятие смерти | Medium pull back | Снег ложится как одеяло |
| scene_08.md | Собака уходит | Wide → extreme wide | Тёплый огонёк лагеря вдали |

Каждая сцена содержит:
- Слой 1 (литературный): кто, что, эмоция, ключевая деталь, связь с темой
- Слой 2 (режиссёрский): тип плана, ракурс, движение камеры, освещение, hex цвета
- Слой 3 (технический): готовый промпт на английском с FORBIDDEN-блоком, @image референсы, инструмент
- Видеопромпт: инструмент, текст, start image, длительность
