# План реструктуризации AI-Cinema
> Дата: 2026-06-02 · Основание: project_analysis.md · Статус: шаг 2 из N

---

## Обзор

**Цель:** превратить текущую структуру «один агент с контекстом в голове» в многоагентный пайплайн, где каждый агент знает что читает, что пишет и когда заканчивает работу.

**Итого:** 20 действий, 7 фаз.

**Правило фаз:** фазы 1–6 — только добавление. Фаза 7 — удаление, только после того как всё новое проверено.

**Что:** создать папку `films/film_01_kostyor/agents/`
**Зачем:** корень для всех агентных инструкций. Без этой папки нет места, куда агенты смотрят за своими задачами.

### Действие 1.2
**Что:** создать `films/film_01_kostyor/agents/00_orchestrator.md`
**Зачем:** главный документ системы — описывает порядок запуска агентов, входные ворота для каждого, цикл от сцены до смонтированного клипа. Без оркестратора каждый агент — изолированный инструмент.

Содержимое:
- Схема запуска: агент 1 → агент 2 → агент 3 → агент 4
- Правило: следующий агент не стартует, пока предыдущий не проставил статус `done` в `production/status.md`
- Ссылки на все четыре файла агентов
- Ссылки на `status.md`, `registry.md`, `transitions.md`

### Действие 1.3
**Что:** создать `films/film_01_kostyor/agents/01_storyboarder.md`
**Зачем:** инструкция агента-раскадровщика. Сейчас агент вынужден читать весь сценарий целиком, угадывать формат вывода и не знает, куда писать результат.

Содержимое:

- Правило завершения: проставить статус `storyboard_done` в `production/status.md` для каждой сцены
