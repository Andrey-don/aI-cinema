> Источник: курс Киселевой. Читать при работе с персонажами и фотореалистичными кадрами.

---

## Что такое Seedream и зачем он нужен

**Seedream (C-Dream 4)** — нейросеть для генерации фотореалистичных изображений.

**Ключевое отличие от Midjourney:**
- Midjourney → атмосфера, художественность, журнальная стилизация
- Seedream → фотореализм, натуральные кадры, **консистентность персонажа**

**Суперсила Seedream:** одного фото достаточно, чтобы перенести персонажа в любую сцену с сохранением внешности. Именно для создания **героя с постоянной внешностью на протяжении всего фильма**.

## Сравнение моделей (по одному промпту)

| Модель | Результат | Когда использовать |
|--------|-----------|-------------------|
| **Seedream 4** | Лучший фотореализм, качество кожи | Персонажи, натуральные кадры, кино |
| Nanobanana | Близко к Seedream | Контекстное редактирование |
| Flux | Художественно, как MJ | Тренировка LoRA-моделей |
| Imogen 4 | Хорошо, но не дотягивает до реализма | Общие задачи |
| Crea (встроенная) | Неплохо, но кожа лица — маска | Быстрые тесты |
| Van 2, QN | Слабее, больше «нейро-вид» | Не рекомендуется |
| ChatGPT Image | Мультяшность, блокирует бренды | Иллюстрации |

**Вывод:** Для фотореализма и персонажей → Seedream 4.

## Как писать промпты

1. Описать сцену языковой модели (ChatGPT/Claude) словами
2. Указать: что происходит, кто герои, где, как снимаем
3. Добавить технические детали: план, фокус, эффекты
4. LLM генерирует промпт → копируем → вставляем в Seedream

**Пример описания для языковой модели:**
```
Я хочу сгенерировать изображение в нейросети Seedream.
[Описание сцены: кто, где, что делает]
[Технические детали: план, ракурс, освещение, объектив]
[Стилистика: фотореализм, как снято на пленку 35мм, зерно]
```

**Опциональные детали (добавляют качества):**
- объектив: `50mm portrait lens`, `85mm f/1.4`
- стиль: `filmed on 35mm film`, `cinematic grain`
- план: `wide shot`, `close-up`, `medium shot`

## Фиксация конкретного лица персонажа

**Workflow:**
1. Подготовить фото референса — крупно лицо, хорошее качество
2. В Seedream: загрузить фото в поле **Image Prompt / Reference**
3. В промпте указать специфику персонажа: цвет волос, прическу, отличительные черты
4. Генерировать → результат будет похож на референс

**Важно:**
- Можно загрузить до **6 референсных изображений**
- Чем точнее описание в промпте совпадает с референсом — тем лучше результат
- При деформации лица: убрать экстремальные ракурсы (фишай), заменить на широкоугольный

## Применение в проекте «Костёр»

- Seedream — основной инструмент для создания **мастер-кадров** Человека и Собаки

- Результат: персонаж остаётся узнаваемым от сцены к сцене
