# Воркфлоу AI-кинопроизводства — два режима

Документ описывает полный производственный процесс в двух режимах:
- **Режим A** — Syntx (активен до 21 июня 2026)
- **Режим B** — Claude Code + Higgsfield MCP (после 21 июня 2026)

Фундамент одинаков в обоих режимах. Меняется только где и как выполняются шаги.

---

## ФУНДАМЕНТ: принципы, общие для обоих режимов

### Трёхслойная структура каждого промпта

Нейросеть обучена на профессиональном кино — говорить с ней нужно на языке кино.

| Слой | Что описывает | Что ломается без него |
|------|---------------|----------------------|
| **Литературный** | Кто, что происходит, зачем, какие эмоции | Нет смысла в кадре |
| **Режиссёрский** | Камера, план, ракурс, движение, свет, цвет | Красивая, но безликая открытка |
| **Технический** | Референсы, консистентность, параметры качества | Лица плывут, персонаж меняется |

**Диагностика:** странное действие → литературный слой. Плоский кадр → режиссёрский. Плывёт лицо → технический.

**Минимум режиссёрского слоя (4 параметра):**
- Положение камеры — от чьего лица смотрим
- Крупность плана — эмоциональная дистанция до героя
- Ракурс — сила, уязвимость или тревога
- Движение камеры — ритм и внимание зрителя

### Значение планов
- **Общий** — задаёт пространство
- **Средний** — показывает взаимодействие
- **Крупный** — передаёт эмоцию
- **Деталь** — добавляет глубину и акценты

### Правило консистентности персонажа (Character Lock)
- Описание персонажа копировать **дословно** в каждый промпт — не перефразировать
- Лист персонажа = технический якорь. Загружать в каждую генерацию с персонажем
- Сцена-эффекты (лёд на бороде, грязь, усталость) — в промпт сцены, **не** в лист персонажа
- Лист персонажа должен быть нейтральным — без сцены, без атмосферы, ровное освещение

### Правило качества цепочки
- Всегда скачивать в 2K перед следующей загрузкой
- Особенно когда в кадре лицо или мелкие детали — без скачивания деградирует качество
- Для простых кадров без лиц допустимо "добавить запрос" напрямую

### Раскадровка раньше видео
Ошибка на уровне раскадровки стоит 1 попытку. Ошибка на уровне видео — 10.
Порядок: **идея → лист персонажа → карта локации → раскадровка → видео**.

### Аннотации раскадровки (3 строки под каждой панелью)
```
CAM:   [движение и тип камеры]
MOVE:  [действие персонажа — коротко]
MOOD:  [атмосфера] / VOICE: [реплика] / STYLE: [техника боя/движения]
```
- MOOD — для драмы и выживания
- VOICE — для диалоговых сцен
- STYLE — для боевых и экшн-сцен

## РЕЖИМ A — Syntx (до 21 июня 2026)

**Принцип:** Claude генерирует промпты → ты вставляешь их в Syntx вручную.

### Шаг 1 — Подготовка персонажа (один раз на весь фильм)

```
1а. Взять лучший мастер-кадр персонажа (PNG из Syntx)
1б. Апскейл → загрузить в NanoBanana Pro + вставить промпт УЛУЧШЕНИЕ КАЧЕСТВА
    → скачать в 2K
1в. Крупный план лица → загрузить апскейл + вставить промпт ВЫЯВЛЕНИЕ ЛИЦА АНФАС
    → сделать 4+ попыток, выбрать лучший → скачать в 2K
1г. Референс-карта → загрузить ОБА (апскейл полного роста + лучший крупный план)
    → вставить промпт РЕФЕРЕНС-КАРТА → скачать
```

**Результат:** три файла на каждого персонажа:
- `chelovek_upscale.png` — апскейленный мастер-кадр
- `chelovek_face.png` — крупный план лица
- `chelovek_refsheet.png` — референс-карта (7 ракурсов)

### Шаг 2 — Подготовка локации (один раз на каждую уникальную среду)

```
2а. Найти или сгенерировать один опорный кадр локации с персонажем
2б. Убрать персонажа → загрузить кадр + запрос "убери персонажа из кадра"
    → скачать чистую локацию
2в. Карта местности → загрузить чистую локацию + вставить промпт ДОРИСОВКА ЛОКАЦИИ
    → получить сетку 3×3 (9 видов той же локации)
    → если недостаточно — перегенерировать, используя понравившиеся кадры как новые референсы
```

**Результат:** `yukon_location_grid.png` — консистентный набор фонов для всего фильма.

### Шаг 3 — Сцена с персонажем в локации

```
3а. Загрузить: кадр локации (из карты местности) + референс-карта персонажа
3б. Простой запрос на русском: "девушка стоит у панели лицом к камере"
    → если не вышло — повторить несколько раз
3в. Апскейл лучшего результата → скачать в 2K
```

### Шаг 4 — Раскадровка сцены (1-2 сцены за раз)

```
4а. Загрузить: кадр сцены с персонажем + карта местности (2 референса!)
4б. Вставить промпт СЮЖЕТНАЯ РАСКАДРОВКА, описать 1-2 события кратко
4в. Сделать минимум 4 варианта → выбрать лучшие панели из каждого
4г. Если окружение неправильное → убедиться что карта местности загружена
```

**Результат:** набор панелей раскадровки для каждой сцены.

### Шаг 5 — Разноплановая раскадровка (выбор лучшего плана)

```
5а. Взять нужную панель из раскадровки → апскейл → скачать
5б. Загрузить + вставить промпт РАСКАДРОВКА — СМЕНА ПЛАНОВ
    → получить 9 планов одного момента (от дальнего до макро)
5в. Выбрать нужный план для анимации
```

### Шаг 6 — Написание видеопромптов (Claude Code → Syntx)

```
6а. Написать Claude: "создай видеопромпт для сцены [описание]"
    → Claude использует ai-filmmaking скилл (Template 3, Variant C)
    → скилл генерирует промпт с @image1, @image2, таймстемпами
6б. Скопировать промпт → вставить в Syntx (Kling 3.0)
    → загрузить референс-карту как @image1
    → загрузить раскадровку как @image2
    → длительность: 15 секунд
```

### Шаг 7 — Склейка клипов

```
7а. Сгенерировать клип сцены N
7б. Сохранить ПОСЛЕДНИЙ кадр клипа
7в. Следующий клип: первое изображение = последний кадр предыдущего клипа
                     второе изображение = следующая панель раскадровки
    → плавный переход без монтажных склеек
7г. Монтаж всех клипов в CapCut
```

### Схема Режима A (коротко)

```
Claude Code (VS Code)               Syntx (вручную)
──────────────────────              ───────────────────────────
Пишет промпты          →  copy/paste  →  NanoBanana Pro
Хранит все файлы                       (апскейл, референс-карта,
Анализирует результаты                  локация, раскадровка)
Генерирует видеопромпты →  copy/paste  →  Kling 3.0 / Seedance
```

## РЕЖИМ B — Claude Code + Higgsfield MCP (после 21 июня 2026)

**Принцип:** Claude делает всё сам — не нужно переключаться между окнами.

### Подключение (один раз)

```
Claude Code → Settings → Connectors → Add Custom Connector
URL: https://higgsfield.ai/mcp
Название: Higgsfield
→ разрешить все запросы
В каждом чате: плюсик → Connectors → убедиться что Higgsfield включён
```

**Требования:** платная подписка Higgsfield + кредиты на аккаунте.

### Важное ограничение

Загрузить изображение напрямую из Claude Code в Higgsfield **нельзя**.
**Обходной путь:** зайти в Higgsfield → Image → плюсик → загрузить файл вручную.
Потом в Claude написать: *"используй последнее изображение, которое я загружал в Higgsfield"* — Claude найдёт его сам в папке uploads.

### Шаг 1 — Одна команда вместо всей подготовки

```
Написать Claude:
"Подготовь персонажа и локацию для сцены 1 «Костра».
Персонаж — Человек (референс в последних генерациях Higgsfield).
Локация — зимний Юкон, рассвет, серое небо.
Используй NanoBanana Pro, формат 9:16."

Claude сам:
→ найдёт референс в Higgsfield
→ сделает апскейл
→ сгенерирует крупный план лица
→ создаст референс-карту
→ создаст карту локации (9 видов)
```

### Шаг 2 — Полный автоматический воркфлоу (сториборд)

```
Написать Claude одной командой:
"Сделай сцену 1 «Костра»:
Человек выходит на тропу с рассветом, собака плетётся сзади.
Используй референс-карту Человека и карту локации Юкона.
Раскадровка 3×3, аннотации CAM/MOVE/MOOD.
Видео в Kling 3.0, 15 секунд, 9:16."

Этапы с подтверждением:
1. Креативный бриф → ты говоришь "продолжай"
2. Референсы → проверяешь
3. Шотлист → проверяешь
4. Промпты для изображений → проверяешь (последний шанс до списания кредитов)
5. Генерация изображений (NanoBanana Pro) → проверяешь
6. Генерация видео (Kling 3.0) → проверяешь
7. Сборка клипов → готово
```

### Шаг 3 — Продолжение истории

```
"Продолжи историю. Человек проваливается под лёд.
Используй последний кадр предыдущего клипа как начало.
Раскадровка от сцены 3."
→ Claude не создаёт новую референс-карту (персонаж тот же)
→ только новая раскадровка + видео
```

### Шаг 4 — Исправление результата

```
Если лицо поплыло:
"Исправь лицо в последнем кадре по референс-карте персонажа"
→ Claude применяет промпт УЛУЧШЕНИЕ + КОРРЕКТИРОВКА ЛИЦА

Если окружение неверное:
"Добавь карту локации как второй референс и перегенерируй раскадровку"
```

### Автопилот (опционально — только desktop-приложение)

```
Routines → New Routine → Remote
Подключить GitHub репозиторий проекта
Расписание: например, ежедневно в 10:00
Инструкция: "генерируй следующую сцену «Костра» по шаблону воркфлоу"
→ Claude генерирует контент по расписанию без участия пользователя
→ Все файлы сохраняются в папки: briefs/, prompts/, images/, videos/
```

### Схема Режима B (коротко)

```
Claude Code (VS Code)
────────────────────────────────────────────────
Получает команду
↓
Пишет промпты → отправляет в Higgsfield MCP → NanoBanana Pro
↓
Получает изображения → показывает в чате → сохраняет в папки
↓
Пишет видеопромпты → отправляет в Higgsfield MCP → Kling / Seedance
↓
Получает видео → показывает в чате → сохраняет в папки
↓
Собирает все клипы → итоговое видео
```

## CLAUDE CODE + СКИЛЛ (справка)

Скилл `ai-filmmaking` установлен в `~/.claude/skills/ai-filmmaking/SKILL.md`.
Активируется автоматически при описании задачи — не нужно писать команду.

**Три шаблона скилла:**
- **Template 1** — Character Sheet (для NanoBanana Pro / GPT Image 2)
- **Template 2** — Storyboard Grid 3×3 с аннотациями (для NanoBanana Pro)
- **Template 3** — Video Prompts, три варианта:
  - Variant A: только текст (нет референсов)
  - Variant B: только раскадровка (@image1)
  - Variant C: лист персонажа + раскадровка (@image1 + @image2 + @image3) ← **наш вариант**

**Правила @image нумерации:**
- Лист персонажа Человека → @image1
- Лист персонажа Собаки → @image2
- Раскадровка → @image3
- Каждый референс — свой номер. Нельзя два разных файла под одним номером.
