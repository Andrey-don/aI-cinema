# Параметры Midjourney v7 — Полный справочник

## Все параметры
| Параметр | Значения | Описание |
|----------|----------|---------|
| --ar | 9:16 / 16:9 / 1:1 | Соотношение сторон. Для видео: 9:16 |
| --v | 7 | Версия модели |
| --q | 1, 2 | Качество (2 = лучше, медленнее) |
| --s | 0–1000 | Стилизация (100 = реализм, 750 = артистизм) |
| --c | 0–100 | Хаос (вариативность результатов) |
| --w | 0–3000 | Weird (необычность) |
| --sref | URL | Референс стиля/атмосферы |
| --cref | URL | Референс персонажа (лицо) |
| --oref | URL | Референс объекта |
| --no | текст | Исключить из генерации |
| --tile | — | Бесшовный паттерн |

## Рекомендуемые настройки
```
# Реалистичная сцена
--ar 9:16 --v 7 --q 2 --s 150

# Портрет персонажа
--ar 9:16 --v 7 --q 2 --s 100

# Фантазийная сцена
--ar 9:16 --v 7 --q 2 --s 500

# С референсом персонажа (консистентность!)
--ar 9:16 --v 7 --cref [URL] --s 100

# Консистентность локации
--ar 9:16 --v 7 --sref [URL_первого_кадра] --s 200
```
