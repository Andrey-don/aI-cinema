# Контекстное редактирование — Flux Kontext, Seedream, NanoBanana
> Источник: курс Киселевой. Читать когда нужно изменить уже готовое изображение персонажа.

---

## Что такое контекстное редактирование

Берёшь готовое изображение и говоришь нейросети: «вот это оставь, а вот это измени».
Модель не генерирует заново, а аккуратно правит только то, что просишь.

**Применение в нашем проекте:**
- Изменить план/ракурс сцены, сохранив лицо персонажа
- Поменять освещение или фон, сохранив персонажа
- Добавить предмет в руки (нож, спичку, варежку)
- Исправить деталь (поза, элемент одежды)

---

## Три инструмента и их суперсила

| Инструмент | Суперсила | Когда использовать |
|-----------|-----------|-------------------|
| **Flux Kontext** | Быстрые мелкие правки | Цвет детали, прическа, убрать элемент |
| **Seedream (C-Dream 4)** | Перенос персонажа в новую среду, смена плана | Новый фон, новый ракурс, новая локация |
| **NanoBanana** | Швейцарский нож: и мелкое, и крупное | Смена позы, добавить предмет, одежда |

**Личная рекомендация Киселевой:**
- Товары в руки → C-Dream
- Одежда → NanoBanana
- Мелкие детали → Flux Kontext

---

## Flux Kontext — быстрые правки

**Где найти в Syntx:** Designs → Flux → настройки модели → Flux Kontext Max → 9:16

**Промпты пишутся просто и коротко:**
```
Измени цвет рубашки на красный
Сделай волосы каштановыми вместо блондинистых
Убери [предмет] с фона
```
В Syntx можно писать на русском.

**Ограничение:** не справляется с кардинальными изменениями (смена позы, плана).

---

## Seedream / NanoBanana — серьёзные изменения

**Где найти в Syntx:** Designs → C-Dream 4 / NanoBanana

**Настройка перед работой:** зайти в настройки модели → выставить 9:16, 4K → сохранить (один раз).

### Что умеют:

**1. Смена плана и ракурса (сохраняя лицо)**
```
Измени крупность и покажи персонажа в полный рост.
Персонаж сидит на стуле. Оставь лицо неизменным.
```

**2. Смена позы**
```
Персонаж должен стоять, а не сидеть, руки вдоль тела.
Всё остальное в кадре оставь без изменений.
```

**3. Добавить предмет в руки**
```
Загружаем: фото персонажа + фото предмета
Промпт: Добавь [предмет] со второй фотографии в руку персонажа с первой фотографии.
```

**4. Смена одежды**
```
Загружаем: фото персонажа + фото одежды
Промпт: Надень одежду со второй фотографии на персонажа с первой.
```

**5. Смена фона / среды (только Seedream)**
```
Загружаем: портрет персонажа + фото нужной локации
Промпт: Оставь лицо и позу такими же, но фон замени на [описание].
```

---

## Ключевые правила

1. **Одно изменение за раз** — несколько правок в одном промпте дают артефакты
2. **Цепочка:** сначала меняем план → потом на этом плане меняем одежду → потом добавляем предмет
3. **До 6 референсных изображений** можно загрузить одновременно
4. **Разрешение исходников** должно совпадать (особенно в NanoBanana)
5. **Простой промпт** иногда работает лучше сложного
6. Не получилось в одной нейросети → пробуй в другой

## Применение для «Костра»

| Задача | Инструмент |
|--------|-----------|
| Сгенерировали крупный план Человека — нужен общий план | Seedream или NanoBanana |
| Нужен ракурс worm's eye / god's eye с тем же персонажем | Seedream |
| Убрать лишний элемент с фона | Flux Kontext или NanoBanana |
| Добавить спички / нож в руки Человека | Seedream (лучше для предметов) |
| Поменять позу собаки | NanoBanana |
| Ноги промокли — нужно добавить лёд/воду на одежду | NanoBanana |
