## ПАРАМЕТРЫ MIDJOURNEY V7

| Параметр | Значения | Что делает |
|---|---|---|
| `--ar` | 9:16 / 16:9 / 1:1 | Соотношение сторон. Для видео всегда 9:16 |
| `--v` | 7 | Версия модели. V7 = максимум детализации |
| `--q` | 1 / 2 | Качество. 2 = медленнее, но лучше |
| `--s` | 0–1000 | Стилизация. 100 = реализм, 750+ = артистизм |
| `--c` | 0–100 | Хаос. 0 = предсказуемо, 100 = непредсказуемо |
| `--w` | 0–3000 | Weird. Необычность, сюрреализм |
| `--sref` | URL / img | Референс стиля (цвет, атмосфера, стиль) |
| `--cref` | URL / img | Референс персонажа (лицо, внешность) |
| `--oref` | URL / img | Референс объекта |
| `--no` | текст | Исключить из генерации |
| `--tile` | — | Бесшовный паттерн |
| `--exp` | 0–10 | Эстетика, экспрессивность |

### Рекомендуемые настройки для кино
```
Реалистичная сцена:     --ar 9:16 --v 7 --q 2 --s 150
Портрет персонажа:      --ar 9:16 --v 7 --q 2 --s 100
Фантазийная сцена:      --ar 9:16 --v 7 --q 2 --s 500
С референсом стиля:     --ar 9:16 --v 7 --sref [URL] --s 200
С референсом персонажа: --ar 9:16 --v 7 --cref [URL] --s 100
```

## АНИМАЦИЯ

### Kling AI 3.0 — лучший выбор для
- Движение персонажей
- Морфинг между кадрами (режим Keyframes)
- Сложные сцены с несколькими объектами
- Длина: 5–10 секунд

### Veo 3.1 Fast — для
- Простые движения камеры
- Природа, окружение
- Быстро и дёшево
- Большинство сцен фильма

### Промпты для анимации (коротко и конкретно)
```
# Движение камеры вперёд
slow dolly push forward, [описание сцены], cinematic

# Следование за персонажем
camera follows [персонаж], steady tracking shot, [действие]

# Статика с атмосферой
[описание сцены], gentle wind movement, atmospheric lighting, 
particles floating, camera slightly drifting

# Морфинг (Kling Keyframes)
smooth morphing transition between [кадр A] and [кадр B],
realistic movement, no distortion, cinematic quality
```

### Параметры анимации Kling 3.0
- **Motion Brush** — указываем зоны и направление движения
- **Keyframes** — морфинг между двумя изображениями
- **Camera Control** — управление движением камеры
- Длина клипа: 5–10 сек на переход

## МОРФИНГ — ЦЕПОЧКА СЦЕН

### Правила для хорошего морфинга
1. Каждый следующий кадр — похожая композиция и ракурс
2. Промпты: 1–2 предложения + ключевые слова
3. Ключевые слова: «плавный», «реалистично», «без деформации»
4. При артефактах: уменьшай сложность движения
5. Промежуточные кадры — дорабатывать в NanoBanana

### Шаблон цепочки морфинга
```
Кадр A → Кадр B:
"[описание перехода], smooth transition, 
realistic movement, [ключевые детали сцены]"

Кадр B → Кадр C:
"[продолжение действия], seamless morphing,
[новый элемент], cinematic quality"
```

## МУЗЫКА — SUNO

### Структура промпта для Suno
```
[жанр], [темп: slow/mid/fast], [инструменты],
[настроение: epic/melancholic/tense/peaceful],
[вокал: yes/no], [дополнительные детали]

Пример:
cinematic orchestral, slow tempo, strings and piano,
melancholic and hopeful, no vocals, 
winter atmosphere, emotional depth
```

### Советы по Suno
- Всегда генерируй 2 варианта, слушай оба
- Добавь «instrumental» если не нужен вокал
- Короткий промпт = стандарт, длинный = индивидуальность
- Сохраняй удачные промпты!
