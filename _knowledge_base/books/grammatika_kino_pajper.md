## ПЛАНЫ И РАКУРСЫ (Глава 1)

### Типы планов
- **Дальний план (Extreme Wide Shot)** — показывает персонажа в окружении среды, локация доминирует. Используй для: вводных кадров, масштаба, одиночества героя.
- **Общий план (Wide Shot / Establishing Shot)** — персонаж виден целиком. Используй для: начала сцены, ориентации зрителя в пространстве.
- **Средний план (Medium Shot)** — от пояса вверх. Самый распространённый в диалогах.
- **Средне-крупный (Medium Close-Up)** — от груди вверх. Акцент на эмоциях при разговоре.
- **Крупный план (Close-Up)** — лицо. Для эмоций, напряжения, ключевых реакций.
- **Сверхкрупный (Extreme Close-Up)** — глаза, губы, деталь. Максимальное напряжение.

### Ракурсы камеры
- **На уровне глаз** — нейтральный, равноправный взгляд
- **Снизу вверх (Low angle)** — персонаж кажется мощным, угрожающим, важным
- **Сверху вниз (High angle)** — персонаж кажется слабым, уязвимым, маленьким
- **Голландский угол (Dutch angle)** — камера наклонена, создаёт дискомфорт, тревогу, нестабильность
- **Птичий глаз (Bird's eye)** — вид сверху, персонаж ничтожен на фоне мира
- **Лягушачий (Worm's eye)** — максимально снизу, героический или пугающий эффект

### Промпты для AI-генерации
```
# Дальний план — природа доминирует
[character description], extreme wide shot, tiny figure in vast [landscape], 
cinematic, 8k, --ar 9:16 --v 7

# Крупный план — эмоция
[character description], close-up portrait, [emotion] expression, 
cinematic lighting, shallow depth of field, --ar 9:16 --v 7

# Голландский угол — тревога
[character description], dutch angle shot, unsettling atmosphere, 
psychological tension, --ar 9:16 --v 7

# Снизу вверх — мощь
[character description], low angle shot, powerful imposing figure, 
dramatic sky background, --ar 9:16 --v 7
```

## ДВИЖЕНИЕ КАМЕРЫ (Глава 3)

### Основные движения
- **Панорама (Pan)** — горизонтальное вращение камеры на оси. Следит за движущимся объектом или раскрывает пространство
- **Наклон (Tilt)** — вертикальное вращение. Раскрывает высоту здания, фигуру персонажа снизу вверх
- **Наезд/Отъезд (Zoom in/out)** — изменение фокусного расстояния без движения камеры. Акцентирует внимание
- **Долли (Dolly)** — движение всей камеры вперёд/назад. Более живое, чем зум
- **Трекинг (Tracking)** — камера движется параллельно объекту
- **Ханд-хелд (Handheld)** — дрожащая камера, эффект документалистики, реализм
- **Стедикам** — плавное движение следом за персонажем

### Промпты для видео (Kling/Veo)
```
# Долли-наезд — напряжение нарастает
slow dolly push in toward [subject], building tension, 
cinematic movement, smooth camera

# Трекинг — следуем за героем
camera tracks alongside [character] walking through [location], 
steady movement, immersive

# Ханд-хелд — хаос, реализм  
handheld camera follows [character], urgent movement, 
documentary style, raw energy

# Панорама — раскрытие локации
slow panoramic reveal of [location], sweeping camera movement,
cinematic establishing shot
```

## ОСВЕЩЕНИЕ (Глава 4)

### Схемы освещения
- **Трёхточечное (Three-point)** — ключевой свет + заполняющий + контровой. Классика, профессионально
- **Нижний свет (Under-lighting)** — снизу вверх, зловещий, хоррор-эффект
- **Естественный свет (Natural light)** — реализм, документальность
- **Контровой (Backlight/Rim light)** — обводка персонажа светом, отделяет от фона
- **Силуэт** — персонаж тёмный на светлом фоне, таинственность

### Настроение через свет
| Настроение | Тип освещения | Цвет |
|---|---|---|
| Романтика | Мягкий рассеянный | Тёплый золотой |
| Ужас / тревога | Жёсткий, нижний | Холодный синий / зелёный |
| Напряжение | Жёсткие тени | Нейтральный |
| Мечта / воспоминание | Пересвет | Белый, размытый |
| Опасность | Красный свет | Красный |
| Тайна | Частичная темнота | Тёмно-синий |

### Промпты освещения
```
# Золотой час — тепло, надежда
golden hour lighting, warm amber tones, long shadows, 
soft natural light, [scene description]

# Нуар — тайна, опасность
film noir lighting, harsh shadows, venetian blind shadow patterns,
high contrast black and white tones, [scene description]

# Хоррор — страх
underlighting, green tinted shadows, horror atmosphere,
single harsh light source below, [character description]

# Силуэт — таинственность
silhouette against bright background, dramatic backlight,
[character] outline only, [location] background
```

## МОНТАЖ (Глава 6)

### Основные принципы
- **Непрерывный монтаж** — незаметные склейки, иллюзия непрерывного времени
- **Параллельный монтаж** — два события одновременно в разных местах
- **Монтаж аттракционов** — столкновение несвязанных образов для создания смысла
- **Матч-кат** — схожий по форме/движению объект в следующем кадре (плавный переход)
- **Смэш-кат** — резкий контрастный переход, шок
- **Джамп-кат** — скачок внутри одной сцены, ощущение дезориентации

### Правило 180 градусов
Камера всегда должна оставаться по одну сторону воображаемой линии между персонажами. Нарушение = зрители запутываются, кто где стоит.

### Правило 30 градусов
При смене ракурса в одной сцене — минимум 30° разница, иначе выглядит как ошибка монтажа.

### Темп монтажа
- **Долгие кадры** → медленный темп → размышление, красота, напряжение ожидания
- **Короткие кадры** → быстрый темп → экшн, паника, хаос, возбуждение

## ЗВУК И МУЗЫКА (Глава 5)

### Типы звука
- **Диегетический** — звук из мира фильма (голоса, шаги, музыка из радио в кадре)
- **Недиегетический** — музыка/звук для зрителя (саундтрек, голос за кадром)
- **Параллельный звук** — звук совпадает с действием
- **Контрапункт** — звук противоречит картинке (радостная музыка + трагедия)

### Функции музыки
- Задаёт эмоциональный тон
- Подсказывает жанр (хоррор vs романтика)
- Создаёт единство разрозненных кадров
- Нагнетает или снимает напряжение

## ЦВЕТ В КИНО (Глава 2)

### Цветовые символы
| Цвет | Значение |
|---|---|
| Красный | Страсть, опасность, кровь, любовь, власть |
| Синий | Грусть, холод, одиночество, тайна, спокойствие |
| Жёлтый/Золотой | Надежда, счастье, предательство, болезнь |
| Зелёный | Природа, зависть, яд, деньги, рост |
| Белый | Чистота, невинность, смерть (в азиатском кино) |
| Чёрный | Смерть, зло, элегантность, тайна |
| Оранжевый | Энергия, опасность, тепло |

### Цветовые схемы
- **Монохромная** — один цвет + его оттенки. Единство, стиль
- **Комплементарная** — противоположные цвета (синий + оранжевый). Напряжение, яркость
- **Аналогичная** — соседние цвета. Гармония, спокойствие
- **Триада** — три равноудалённых цвета. Динамика, визуальный интерес

## ГОЛЛИВУДСКИЙ СТИЛЬ (Глава 10)

### Ключевые элементы
1. **Вводный кадр** — начало сцены с общего плана, ориентация зрителя
2. **Обратный монтаж (Shot-reverse-shot)** — диалог: A говорит → B слушает → B говорит
3. **Взгляд-объект (Eyeline match)** — персонаж смотрит → следующий кадр то, что он видит
4. **Крупные планы эмоций** — лицо в ключевые моменты
5. **Разрешение конфликта** — каждая сцена имеет начало, середину, конец

### Создатели голливудского стиля
- **Д.У. Гриффит** — параллельный монтаж, матч-кат, движение камеры, манипуляция временем
- **Сергей Эйзенштейн** — монтаж аттракционов, интеллектуальный монтаж
- **Орсон Уэллс** — длинный план, нижние ракурсы, глубина резкости

## СТОРИТЕЛЛИНГ И СТРУКТУРА (Главы 8, 9, 11)

### Трёхактная структура
- **Акт 1** (25%) — Экспозиция. Знакомство с миром, героем, конфликтом. Поворотная точка.
- **Акт 2** (50%) — Конфронтация. Препятствия нарастают. Герой меняется. Кризис.
- **Акт 3** (25%) — Развязка. Финальная схватка. Разрешение. Новый статус-кво.

### Типы персонажей
- **Протагонист** — главный герой, через него история
- **Антагонист** — противостоит герою (не обязательно злодей)
- **Ментор** — помогает герою расти
- **Трикстер** — нарушает правила, комедийное облегчение

### Арка персонажа
```
Начало: герой [качество/ограничение] →
Испытание: сталкивается с [конфликт] →
Трансформация: [что меняется внутри] →
Конец: герой стал [новое качество]
```

## ЖАНРЫ И ИХ ВИЗУАЛЬНЫЙ ЯЗЫК (Главы 12-25)

### Хоррор
- Низкий ключ освещения, длинные тени
- Голландские углы
- Медленные наезды + внезапные скачки
- Звук: тишина → шок

### Нуар
- Высокий контраст, полосы теней
- Дождь, ночь, город
- Роковая женщина, усталый детектив
- Монохром или приглушённые холодные тона

### Экшн
- Короткий монтаж
- Ханд-хелд камера
- Низкие и крайние ракурсы
- Движение в кадре всегда

### Мелодрама / Романтика
- Мягкий свет, тёплые тона
- Долгие крупные планы лиц
- Плавные движения камеры
- Музыка как эмоциональный комментарий

## ПРАКТИЧЕСКИЕ ПРАВИЛА ДЛЯ AI-ПРОДАКШНА

### Консистентность персонажа между сценами
1. Всегда используй **--sref** с референсным изображением персонажа
2. Зафиксируй в промпте: цвет глаз, цвет волос, длину волос, отличительные черты
3. Одна и та же базовая фраза описания персонажа во всех промптах
4. Используй **--cref** для Character Reference (Midjourney v7)

### Консистентность локации
1. Первый кадр локации — создай с максимальной детализацией
2. Сохрани как **--sref** для всех последующих сцен в этой локации
3. Зафиксируй: время суток, освещение, ключевые элементы фона

### Принцип раскадровки
```
Для каждой сцены определи:
1. Где начинается сцена? (Вводный кадр)
2. Что нужно показать крупно? (Эмоция/деталь)
3. Как сцена заканчивается? (Финальный кадр)
4. Как переходим к следующей? (Тип монтажного перехода)
```
