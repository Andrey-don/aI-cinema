# Алгоритм генерации идеи фильма
> Источник: онлайн-семинар «Идея» от 11.05.2026
> Связан с: `films/film_NN/agents/00_developer.md`

---

## Главный принцип

Идея не должна приходить готовой. Она приходит как **искра** — крошечный образ, странность, эмоция. Задача: поймать эту искру немедленно и развернуть по структуре.

**LLM не заменяет автора** — она помогает развить и варьировать идею. Сначала — твоя искра. Потом — LLM для вариативности.

---

## Шаг 1 — Фиксация (первые 60 секунд)

Записать сразу, пока не потеряла эмоциональную окраску. Через час — потеряна. Через сутки — исчезла.

**Инструменты:**
- Голосовая заметка на телефоне / часах (одна кнопка → говоришь)
- Карточка в Notion / Evernote — папка «Входящие идеи»
- Бумага и ручка (особенно во время медитации)

**Правило минимума** — записать хотя бы 3 пункта:
1. Образ (кто / что появилось)
2. Странность (что необычного)
3. Эмоция (что ты почувствовал)

**Антипаттерны — не делать:**
- ❌ Ждать готового сюжета перед записью
- ❌ Включать внутреннего критика («это бред»)
- ❌ Записывать сложными длинными текстами
- ❌ Откладывать на «потом»
- ❌ Отдавать генерацию идеи полностью в LLM

## Шаг 2 — Анатомия идеи

Разобрать пойманный образ по составляющим:

| Элемент | Вопрос |
|---------|--------|
| **Образ** | Что именно ты увидел? (картинка, сцена, лицо) |
| **Вопрос** | Что это вызывает? Что будет дальше? |
| **Эмоция** | Тревога / одиночество / надежда / страх / радость / шок |
| **Персонаж** | Кто он? Не просто «человек» — а уставший клерк / непризнанный художник / мать в ожидании |
| **Странность** | Что нарушает реальность? Что здесь невозможного? |
| **Конфликт** | Герой против себя / против реальности / против другого |
| **Смысл** | Какая универсальная человеческая проблема здесь зашита? |
| **Финал** | Чем это заканчивается? Что изменилось? |

## Шаг 3 — Универсальная матрица

Читать слева направо, по диагонали. Можно войти с любой клетки.

```
┌─────────┬────────────┬───────────┐
│  ИСКРА  │  ВОПРОС    │  ЭМОЦИЯ   │
├─────────┼────────────┼───────────┤
│ПЕРСОНАЖ │  ПРОБЛЕМА  │ ОКРУЖЕНИЕ │
├─────────┼────────────┼───────────┤
│КОНФЛИКТ │   СМЫСЛ    │   ФИНАЛ   │
└─────────┴────────────┴───────────┘
```

**Как использовать:** Зафиксировал образ (Искра) → задаёшь вопрос (Вопрос) → чувствуешь эмоцию → определяешь персонажа → находишь его проблему → помещаешь в окружение → формулируешь конфликт → ищешь смысл → придумываешь финал.

Можно начать с Проблемы и двигаться к Искре. Или с Эмоции — к Персонажу.

## Шаг 4 — Визуальная метафора

**Правило:** не описывай проблему словами — переводи её в визуальный образ.

| Состояние | Визуальная метафора |
|-----------|---------------------|
| Усталость от рутины | Стены комнаты медленно сдвигаются |
| Подавленная мечта | Тень живёт отдельно от человека |
| Одиночество | Человек невидим — все проходят сквозь него |
| Страх ошибиться | Двери в коридоре исчезают одна за другой |
| Принятие себя | Тень возвращается, в руке появляется кисть |
| Несвобода | За открытым окном не улица, а океан |

**Метод:** задай вопрос — «как это ВЫГЛЯДИТ?». Используй ассоциативный ряд: цвет, предметы, природные явления, физические ощущения.

**Кулешовский принцип:** нейтральное лицо + предмет (гроб, еда, женщина) = зрители приписывают эмоцию. Метафора работает так же.

---

## Шаг 5 — Три архетипические движущие силы

Любая история держится на одном из трёх:

| Сила | Вопрос к герою | Примеры тем |
|------|---------------|-------------|
| **Страх** | От чего герой убегает? | Смерть, провал, одиночество, потеря |
| **Мечта** | К чему герой отчаянно стремится? | Любовь, свобода, признание, деньги |
| **Внутренний конфликт** | Кем герой хочет быть против кем является? | Клерк-мечтающий-стать-художником |

Лучшие истории совмещают все три.

## Шаг 6 — Архитектура микроистории (15–30 секунд)

Для короткого формата (Reels/Shorts/TikTok):

```
0–5 сек    ЭКСПОЗИЦИЯ   — знакомство с миром, всё обычно
5–10 сек   ЗАВЯЗКА      — странное событие начинается
10–18 сек  РАЗВИТИЕ     — ситуация нарастает, конфликт усиливается
18–25 сек  КУЛЬМИНАЦИЯ  — пик напряжения
25–30 сек  РАЗВЯЗКА     — финальный визуальный поворот
```

**Формула:** `ПРОБЛЕМА → ВИЗУАЛЬНАЯ МЕТАФОРА → НЕОБЫЧНОЕ СОБЫТИЕ → ФИНАЛЬНЫЙ ПОВОРОТ`

**Пример (тень живёт отдельно):**
- Проблема: клерк живёт не своей жизнью (мечтает быть художником)
- Метафора: тень отделяется и действует самостоятельно
- Событие: тень рисует светящуюся дверь на стене
- Финал: герой касается двери, тень возвращается — в руке появляется кисть

## Шаг 7 — Жанр как система правил

Жанр определяет идеи, которые работают:

| Жанр | Правило | Что делает обычное |
|------|---------|-------------------|
| **Horror** | Обычное становится пугающим | Принтер печатает мысли сотрудников |
| **Thriller** | Недосказанность, паузы, напряжение | Подсказка скрыта в отражении лужи |
| **Sci-fi** | Технология меняет реальность | Комната превращается в съёмочную площадку |
| **Melodrama** | Боль о потере / любви | Замёрзшие волны у пляжа с летней девушкой |
| **Comedy** | Несовместимое соединяется | Самурай с катаной в супермаркете |

## Шаг 8 — Искусство случайных сочетаний (для виральности)

Соединить два образа, которые не сочетаются:

```
Необычный персонаж + Неожиданная локация = Захват внимания
```

**Примеры:**
- Самурай → выбирает точилку для катаны в супермаркете
- Космонавт в скафандре → сидит в бане
- Робот → жарит блины
- Медведь → идёт на рыбный рынок (где рыбы заняли места покупателей)

**Почему работает:** нарушает паттерн восприятия → вызывает вопрос «а что дальше?» → останавливает скролл.

## Шаг 9 — Источники вдохновения

| Источник | Что искать | Как использовать |
|----------|-----------|-----------------|
| **Pinterest** | Настроение, атмосфера, персонажи, локации | Создать доску проекта, искать на английском |
| **Behance** | Дизайн, шрифты, необычные персонажи | Визуальные референсы для стиля |
| **Escape AI** (escapeai.io) | Лучшие AI-видео работы | Вдохновение и анализ техник |
| **Кино без звука** | Камера, свет, монтаж | Смотреть понравившиеся сцены без звука |
| **Love, Death + Robots** | Короткий разножанровый формат | Структура микроисторий |

**Как читать визуальный референс:**
1. Кто в кадре?
2. Где он находится?
3. Какое настроение?
4. Что может случиться через 5 секунд?

## Шаг 10 — Работа с LLM для развития идеи

LLM не генерирует идею вместо тебя — она помогает найти варианты внутри твоей структуры.

**Плохой запрос:** «Придумай мне идею для видео» ❌
**Хороший запрос:**
```
У меня есть:
- Персонаж: [описание]
- Локация: [описание]
- Проблема: [одно предложение]
- Жанр: [horror / melodrama / comedy / sci-fi]

Придумай 5 вариантов необычного события (странности),
которое произойдёт с этим персонажем в этой локации.
Для каждого — финальный визуальный поворот.
Формат: без диалогов, 3–5 предложений на вариант.
```

**Принцип работы с LLM:**
1. Даёшь роль (сценарист / режиссёр / раскадровщик)
2. Даёшь пример эталонного результата
3. Получаешь 5–10 вариантов
4. Отбираешь лучшее
5. Развиваешь выбранный вариант дальше

---

## Шаг 11 — Хранение идей

**Структура папок в Notion/Evernote:**
```
📥 Входящие (сырые образы)
📁 По персонажам
📁 По странностям
📁 По локациям
📁 По эмоциям
📁 Готово к разработке
```

**Правило:** возвращаться к папке «Входящие» раз в неделю. Часть идей окажется бредом — это нормально. 1 из 10–20 станет основой фильма.

---

## Выход из алгоритма — готовая концепция

Когда пройдены все шаги, фиксируется:

| Элемент | Результат |
|---------|-----------|
| Логлайн | Одно предложение: [кто] [хочет чего] [но мешает что] |
| Жанр + настроение | Одно слово + цветовой тон |
| Персонаж | Краткое описание + внутренний конфликт |
| Структура сцен | 6–10 сцен, каждая одной строкой |
| Финальный образ | Последний кадр — что изменилось? |

Далее — передать в `agents/01_storyboarder.md`.
