# Смена планов и раскадровка в AI-кино
> Источник: видеоурок Сергея Нейрографа «AI КИНО с помощью НОВОГО метода»
> Инструменты: NanoBanana Pro, Flux 2.0 Max, Syntx, CapCut, ChatGPT

---

## 1. Зачем нужна смена планов

Смена планов — это пульт управления вниманием зрителя:
- 3 секунды без смены плана → зритель уходит
- Резкий переход даёт мозгу удовольствие
- Смена планов ставит акценты, управляет чувствами, раскрывает суть истории

**Кадр = буква. Склейка двух кадров = слово или предложение.**

---

## 2. Раскадровка vs Смена планов — это разные вещи

| | Раскадровка | Смена планов |
|---|---|---|
| Когда | До генерации | Во время генерации |
| Что | План, инструкция, карта сцены | Приём, язык, способ управлять вниманием |
| Аналогия | Чертёж | Строительство |

**Ошибка новичков:** называть сетку 3×3 из NanoBanana «раскадровкой». Это не раскадровка — это набор планов одного персонажа.

## 3. Грамматика визуального повествования

### Правило 1 — Крупный план (Гриффит, 1910)
- Окно во внутренний мир героя
- Показывает эмоции, мысли, решения
- На общем плане эмоции персонажа не видны

### Правило 2 — Параллельный монтаж
- Два события одновременно: эмоция человека + мрачное небо
- Формирует у зрителя понимание контекста
- Пример: бегущий человек + дверь = он спешит туда

### Правило 3 — Эффект Кулешова (1 + 1 = 3)
- Один нейтральный кадр + контекст = новый смысл
- Лицо + еда = голод
- Лицо + гроб = скорбь
- Лицо + красивая женщина = вожделение
- **Смысл создают не актёр, а кадры вокруг него**

### Правило 4 — Правило третей
- Персонаж не в центре, а ближе к левой или правой трети кадра
- Исключение: крупный план или намеренный акцент
- Обязательно прописывать в промптах для NanoBanana

## 4. Типы планов (шпаргалка)

| План | Описание | Когда использовать |
|------|----------|-------------------|
| Общий (установочный) | Персонаж + окружение целиком | Знакомство с локацией |
| Средний | Персонаж по пояс | Действие, диалог |
| Крупный | Лицо, эмоция | Внутренний мир героя |
| Деталь | Часть тела, предмет | Акцент на важной детали |
| Вид сзади | Персонаж спиной | Движение, уход, неизвестность |
| Вид сверху | Камера сверху | Уязвимость, масштаб |
| Вид снизу | Камера снизу | Сила, угроза, величие |
| Через плечо | Камера за плечом | Диалог, преследование |
| POV | Глазами персонажа | Погружение, субъективность |
| Широкоугольный снизу | Эффект монументальности | Финальные кадры, акцент |

## 5. Рабочий процесс создания планов (NanoBanana Pro)

### Шаг 1 — Референсы на вход
Отдавать модели минимум два изображения:
1. Персонаж в полный рост с окружением (одежда, обстановка)
2. Крупный план лица (чтобы нейронка точно знала лицо)
3. Детали, которые не получились при первых итерациях

### Шаг 2 — Промпт через итератор
- Написать задачу: «9 планов камеры персонажа»
- Указать конкретные планы (общий, средний, крупный, сзади, снизу...)
- Итератор делит промпт на отдельные задачи для каждого плана

### Шаг 3 — Генерация и оценка
- Генерировать пачками (Run Model)
- Смотреть на консистентность персонажа
- Фиксировать что не получилось (конкретные детали)

### Шаг 4 — Итеративная доработка
- Скриншот конкретных несовпадающих элементов
- Добавить их как дополнительные референсы
- Дописать в промпт: «добавь детали из этих референсов»
- Перегенерировать только проблемные планы

## 6. Тренировка ChatGPT для генерации кинопромптов

Автор использует отдельный чат GPT, сохранённый в папке — фактически обученный агент.

**Алгоритм:**
1. Создать отдельный чат (не бот) в ChatGPT
2. Дать образец промпта нужного формата
3. Загрузить референс персонажа
4. Написать задачу: «9 планов камеры — общий, средний, крупный, 3/4, снизу, сзади, через плечо...»
5. GPT генерирует промпты на английском с учётом сцены, освещения, окружения
6. Тестировать → фиксировать что не так → дообучать в диалоге

**Ключевые правила для GPT:**
- «Учитывай правило третей — персонаж не в центре»
- «Давай краткое обозначение плана перед промптом»
- «Учитывай принцип 180°»

## 7. Сборка в CapCut

- Загрузить все шоты на таймлайн
- Функция «Сделайте цвета единообразными» (сопоставление цветов) — автоматически синхронизирует освещение между сценами
- Выбрать эталонный шот → CapCut подтянет остальные
- Озвучка: ElevenLabs → наложить на таймлайн
- Музыка: Suno → отдельный трек
- Экспорт с выбором обложки

---

## 8. Ключевые инсайты

- Нейросети знают «буквы», но не знают «грамматику» — её должен знать режиссёр
- Не промпты важны в первую очередь — важен язык кино
- Итеративность нормальна: в настоящем кино тоже снимают много дублей
- Консистентность достигается через несколько референсов одновременно
- Правило третей нужно явно прописывать в промпте — модели его не знают
