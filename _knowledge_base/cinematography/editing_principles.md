# Принципы монтажа — Шпаргалка

## Ключевые правила
- **Правило 180°** — камера всегда по одну сторону от воображаемой линии между героями
- **Правило 30°** — при смене ракурса минимум 30° разница
- **Взгляд-объект** — персонаж смотрит → следующий кадр то, что он видит

## Типы переходов
| Переход | Эффект | Когда использовать |
|---------|--------|-------------------|
| Прямая склейка (Cut) | Нейтральный | Всегда, по умолчанию |
| Матч-кат | Связь двух образов | Смена времени/места |
| Наплыв (Dissolve) | Плавно, мягко | Воспоминания, сон |
| Затемнение | Конец главы | Смена акта |
| Морфинг | Трансформация | Метаморфоза персонажа |

## Темп монтажа
- Долгие кадры (5–10 сек) → медленный темп → размышление, красота, ожидание
- Короткие кадры (1–2 сек) → быстрый темп → экшн, паника, хаос

## Голливудские клише (знать, чтобы использовать или избегать)
1. Вводный кадр → средний → крупный (стандартная сцена)
2. Обратный монтаж в диалоге (shot-reverse-shot)
3. Крупный план в кульминации
4. Параллельный монтаж для нагнетания напряжения
