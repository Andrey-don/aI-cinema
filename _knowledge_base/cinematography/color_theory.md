# Цвет в кино — Шпаргалка

## Символика цветов
| Цвет | Значение | Применение |
|------|----------|-----------|
| Красный | Страсть, опасность, кровь, любовь | Кульминация, угроза |
| Синий | Грусть, холод, одиночество, тайна | Зима, депрессия, ночь |
| Золотой | Надежда, счастье, прошлое | Воспоминания, тепло |
| Зелёный | Природа, яд, зависть | Лес, болезнь |
| Белый | Чистота, смерть, пустота | Арктика, финал |
| Чёрный | Смерть, зло, неизвестность | Антагонист, тайна |
| Оранжевый | Огонь, энергия, опасность | Костёр, экшн |
