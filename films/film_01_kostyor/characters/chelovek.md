# Персонаж: Человек (The Man)

## Визуальный профиль (по тексту Лондона)
- Возраст: 35 лет
- Пол: мужской, американец, чечако (новичок на Клондайке)
- Волосы: тёмные, полностью скрыты под шапкой
- Борода: рыжая, густая, покрыта плотной янтарно-жёлтой ледяной коркой
- Кожа: обветренная, обмороженные красные скулы, большой нос открыт морозу
- Глаза: бледно-серо-голубые, зоркие, упрямые, без воображения
- Одежда: тяжёлая меховая парка, шапка с наушниками, толстые меховые рукавицы, мокасины до середины икры, толстые шерстяные носки
- Без рюкзака, без ремней, без снаряжения — идёт налегке
- Завтрак завёрнут в носовой платок, спрятан под рубашкой — снаружи не виден

## Правила использования референсов
- Полный рост → Image Prompt = фронтальный мастер-кадр в полный рост
- Портрет → Image Prompt = портретный мастер-кадр (анфас)
- Image Strength = 30–40%
- Формат референса: PNG (не JPG)
- Референс берётся только из сгенерированных в Syntx картинок

## Эволюция образа по сценам
- Сцены 1–3: уверенный, борода только начинает замерзать
- Сцены 4–7: нарастающее беспокойство, борода сильно обледенела
- Сцены 8–11: паника, отчаяние, пальцы не слушаются
- Сцены 12–13: покой, принятие, закрытые глаза
