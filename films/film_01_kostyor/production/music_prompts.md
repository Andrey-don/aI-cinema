# Музыкальные промпты — Костёр

## Основная тема (Suno)
```
cinematic orchestral, slow tempo, solo cello and sparse piano,
melancholic and inevitable, no vocals, instrumental only,
winter wilderness atmosphere, sparse minimalist arrangement,
emotional depth, gradual diminuendo to silence,
Jack London arctic survival drama
```

## Тема надежды (Сцены 1–4)
```
solo violin with light strings, tentative hopefulness,
cold but beautiful, winter landscape music,
no percussion, delicate, instrumental
```

## Тема нарастания (Сцена 5–6)
```
strings building tension, cello becomes prominent,
mounting dread, no resolution, arctic survival,
dark orchestral, no vocals
```

## Финальная тема (Сцены 7–8)
```
solo cello, extremely slow, acceptance and peace,
minimal piano notes, vast emptiness,
nature's indifference rendered in music,
fading to silence, no vocals
```
