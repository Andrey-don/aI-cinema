# Протокол передачи кадров — «Костёр»
> Правило: последний кадр сцены N = первый кадр (start image) сцены N+1.
> Агент 3 (Видеограф) заполняет этот файл по мере одобрения клипов.
> Агент 3 не генерирует клип N+1, пока не заполнена строка перехода N→N+1.

---

| Переход | Последний кадр сцены N | Start image сцены N+1 | Статус |
|---------|------------------------|-----------------------|--------|
| Сц.01 → Сц.02 | — | — | ⏳ нет |
| Сц.02 → Сц.03 | — | — | ⏳ нет |
| Сц.03 → Сц.04 | — | — | ⏳ нет |
| Сц.04 → Сц.05 | — | — | ⏳ нет |
| Сц.05 → Сц.06 | — | — | ⏳ нет |
| Сц.06 → Сц.07 | — | — | ⏳ нет |
| Сц.07 → Сц.08 | — | — | ⏳ нет |

---

## Как заполнять

1. Скачать финальный кадр клипа в 2K
2. Сохранить в `assets/images/scene_NN_last_frame.jpeg`
3. Заполнить строку: путь к файлу в обе колонки (N и N+1)
4. Поставить статус `✅ готов`
5. Только после этого передать start image агенту 3 для следующей сцены
