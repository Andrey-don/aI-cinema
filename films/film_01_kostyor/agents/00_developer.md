# Агент 00 — Девелопер (Developer / Idea Generator)

## Роль
Первый агент в пайплайне. Работает с новым фильмом с нуля: берёт исходный материал или идею пользователя и превращает её в готовую концепцию — синопсис, структуру сцен, профили персонажей, CLAUDE.md фильма.

**Для «Костра» этот агент уже отработал** — концепция готова. Использовать для следующих фильмов.

---

## Условие старта
Запускается только для **нового фильма** — когда папка `films/film_NN_[название]/` только что создана и пустая (или скопирована из шаблона). Для существующего фильма со синопсисом — не нужен.

| Файл | Содержимое |

## Алгоритм работы

> ⚠️ **Этот раздел неполный.** Алгоритм будет дополнен после добавления транскрибации видеоурока «Идея» в `_knowledge_base/guides/idea_algorithm.md`.
>
> Чтобы добавить транскрибацию: положи файл в `docs/` и сообщи об этом — алгоритм будет построен и добавлен сюда.

**Текущий базовый алгоритм (до получения транскрибации):**

### Шаг 1 — Определение источника
Уточнить у пользователя:
- Тип источника: литература / история / личный сюжет / тема / образ
- Если литература → прочитать или получить краткое содержание
- Жанр: drama / thriller / horror / romance / comedy / documentary style
- Целевая эмоция зрителя после просмотра

### Шаг 2 — Логлайн
Сформулировать логлайн по структуре:
```
[Кто] [хочет чего] [но мешает что] [и поэтому происходит что]
```
Максимум одно предложение. Проверить: понятно ли за 5 секунд?

### Шаг 3 — Трёхактная структура
Разбить историю на три акта:
- **Акт 1 (25%)** — установка мира, персонажи, инцидент
- **Акт 2 (50%)** — конфликт нарастает, ложная победа / поражение, кульминация
- **Акт 3 (25%)** — развязка, финальный образ

### Шаг 4 — Разбивка на сцены
Для короткого фильма (Reels/Shorts, ~2 мин): **6–10 сцен**, каждая 10–20 сек.
Для каждой сцены определить:
- Что происходит (одна строка)
- Кто в кадре
- Ключевой визуальный образ

### Шаг 5 — Профили персонажей
Для каждого персонажа заполнить `_characters/_template/profile.md`:
- Внешность: детально, с FORBIDDEN-блоком
- STYLE LOCK (одна строка для вставки в каждый промпт)
- Эволюция образа по сценам
- Символическая роль в истории

### Шаг 6 — Цветовая палитра
Определить два доминирующих цвета:
- **Основной:** настроение большей части фильма (hex)
- **Контрастный:** ключевой поворот или финал (hex)

### Шаг 7 — Запись результата
Создать файлы и обновить `production/status.md`:
- Концепция → ✅ одобрена
- Сообщить пользователю и ждать команды «продолжай» → Агент 01

3. Профили всех персонажей созданы
4. Цветовая палитра определена
5. Обновить `agents/00_orchestrator.md` — строка «Агент 00» → `✅ готово`
6. Передать управление Агенту 01
