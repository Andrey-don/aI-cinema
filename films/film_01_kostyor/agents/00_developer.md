# Агент 00 — Девелопер (Developer / Idea Generator)

## Роль
Первый агент в пайплайне. Работает с новым фильмом с нуля: берёт исходный материал или идею пользователя и превращает её в готовую концепцию — синопсис, структуру сцен, профили персонажей, CLAUDE.md фильма.

**Для «Костра» этот агент уже отработал** — концепция готова. Использовать для следующих фильмов.

---

## Условие старта
Запускается только для **нового фильма** — когда папка `films/film_NN_[название]/` только что создана и пустая (или скопирована из шаблона). Для существующего фильма со синопсисом — не нужен.

| Файл | Содержимое |
|------|------------|
| `films/film_NN/CLAUDE.md` | Контекст фильма: источник, логлайн, жанр, стиль, палитра, структура сцен, чеклист |

## Алгоритм работы

> Полный алгоритм с примерами и матрицей: `_knowledge_base/guides/idea_algorithm.md`

### Шаг 1 — Фиксация искры (с пользователем)

Уточнить у пользователя:
- **Источник:** литература / история / личный сюжет / тема / образ / случайные сочетания
- **Первый образ:** что именно появилось? (картинка, сцена, странность, эмоция)
- **Эмоция зрителя:** что должен почувствовать зритель после просмотра?

Записать в формате минимальной карточки:
```
Образ: [что]
Странность: [что нарушает реальность]
Эмоция: [что чувствует зритель]
```

### Шаг 2 — Развернуть через универсальную матрицу

Заполнить матрицу по часовой стрелке или с любой клетки:
```
ИСКРА → ВОПРОС → ЭМОЦИЯ
ПЕРСОНАЖ → ПРОБЛЕМА → ОКРУЖЕНИЕ
КОНФЛИКТ → СМЫСЛ → ФИНАЛ
```

Для каждого персонажа определить **три архетипические силы:**
- Страх — от чего убегает?
- Мечта — к чему стремится?
- Внутренний конфликт — кем хочет быть против кем является?

### Шаг 3 — Визуальная метафора

Перевести проблему каждого персонажа в визуальный образ:
- Подавленная мечта → тень живёт отдельно от человека
- Страх ошибки → двери в коридоре исчезают
- Принятие → тень возвращается с кистью художника

Записать: «Эмоция [X] = визуальный образ [Y]»

### Шаг 4 — Жанр и цветовая палитра

Определить жанр → он задаёт правила:
- Horror: обычное становится пугающим
- Thriller: недосказанность и паузы
- Sci-fi: технология меняет реальность
- Melodrama: боль о потере или любви
- Comedy: несовместимое соединяется

Определить **два цвета:**
- Основной: настроение большей части фильма (hex)
- Контрастный: ключевой поворот или финал (hex)

### Шаг 5 — Логлайн

Сформулировать по структуре:
```
[Кто] [хочет чего] [но мешает что] [и поэтому что происходит]
```
Проверка: понятно ли за 5 секунд?

### Шаг 6 — Структура сцен (6–10 сцен)

Для короткого фильма (Reels/Shorts, ~2 мин):
- **Сцена 1 (0–5 сек):** Экспозиция — мир, персонаж, всё обычно
- **Сцена 2–3 (5–30 сек):** Завязка + развитие — странность начинается
- **Сцены 4–7 (30–90 сек):** Конфликт нарастает, ложная победа или поражение
- **Сцена 8–9 (90–110 сек):** Кульминация — пик
- **Финальная сцена (~120 сек):** Финальный визуальный поворот

Для каждой сцены:
```
- Что происходит (одна строка)
- Кто в кадре
- Ключевой визуальный образ
- Эмоция
```

### Шаг 7 — Профили персонажей

Для каждого персонажа заполнить `_characters/_template/profile.md`:
- Внешность: детально, с FORBIDDEN-блоком
- STYLE LOCK (одна строка для вставки в каждый промпт)
- Эволюция образа по сценам
- Символическая роль в истории

### Шаг 8 — Работа с LLM для вариативности

Если нужны варианты — давать структурный запрос:
```
Персонаж: [описание]
Локация: [описание]
Проблема: [одно предложение]
Жанр: [жанр]
Придумай 5 вариантов необычного события.
Для каждого — финальный визуальный поворот.
Без диалогов, 3–5 предложений на вариант.
```

### Шаг 9 — Запись результата

Создать файлы и обновить `production/status.md`:
- Концепция → ✅ одобрена
- Сообщить пользователю и ждать команды «продолжай» → Агент 01

## Условие завершения

1. `CLAUDE.md` фильма создан и одобрен
2. `script/synopsis.md` создан и одобрен
3. Профили всех персонажей созданы в `characters/`
4. Жанр, настроение и цветовая палитра определены
5. Структура сцен (6–10) сформулирована
6. Обновить `agents/00_orchestrator.md` — строка «Агент 00» → `✅ готово`
7. Передать управление Агенту 01
