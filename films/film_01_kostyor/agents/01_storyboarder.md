# Агент 01 — Раскадровщик (Storyboarder)

## Роль
Переводит литературный сценарий в визуальный план: для каждой из 8 сцен создаёт трёхслойный файл раскадровки, готовый к передаче агенту 02.

## Условие старта
Читает `production/status.md` — запускается только если все строки в **Секции В** (сцены) имеют статус `⏳ нет` в колонке «Раскадровка». Если хотя бы одна сцена уже в работе или одобрена — уточняет у пользователя.

---

## Что читает

| Файл | Зачем |
|------|-------|
| `script/synopsis.md` | Трёхактная структура, темы, ключевые повороты |
| `script/london_kostyor_film_source.md` | Режиссёрские заметки, детали из рассказа Лондона |
| `characters/chelovek.md` | Профиль Человека: характер, эволюция по сценам |

| `characters/sobaka_prompts_FULL.md` | BASE-блок и доступные действия/эмоции/освещение для Собаки |
| `assets/registry.md` | Какие референсы уже одобрены (@image1, @image2) |

## Что пишет

Создаёт или обновляет **8 файлов** в `storyboard/scenes/`:
```
scene_01.md … scene_08.md
```

### Обязательный формат каждого файла

```markdown
# Сцена NN: [Название]
> Статус раскадровки: ⏳ в работе / ✅ одобрена

---

## Слой 1 — Литературный
- **Кто:** [персонажи в сцене]
- **Что происходит:** [действие одним абзацем]
- **Доминирующая эмоция:** [одно слово / фраза]
- **Ключевая деталь:** [то, что нельзя потерять при генерации]
- **Связь с темой:** [к какой теме фильма относится]

## Слой 2 — Режиссёрский
- **Тип плана:** [крупный / средний / общий / деталь / экстремально общий]
- **Ракурс:** [анфас / профиль / сверху / снизу / POV / нидерландский]
- **Движение камеры:** [статика / наезд / отъезд / проезд / панорама / подъём]
- **Освещение:** [описание источника, направления, качества света]
- **Цветовая температура:** [hex или словами + настроение]
- **Примечание режиссёра:** [что важно передать визуально]

## Слой 3 — Технический
- **Промпт (изображение):** [готовый текст на английском — полный, с FORBIDDEN-блоком]
- **@image1:** [ID из registry.md — референс персонажа 1]
- **@image2:** [ID из registry.md — референс персонажа 2, если нужен]
- **Инструмент генерации:** NanoBanana Pro (основной) / Seedream (альтернатива)
- **Статус кадра:** ⏳ нет

## Промпт для видео
- **Инструмент:** Kling AI 3.0 (практика) / Seedance 2.0 (финал)
- **Текст промпта:** [готовый текст движения камеры и действия]
- **Start image:** [из production/transitions.md — заполняется агентом 03]
- **Длительность:** 15 сек (если не указано иное)
- **Статус клипа:** ⏳ нет
```

## Правила работы

1. **Промпт слоя 3 = BASE-блок + описание конкретной сцены.** BASE-блок копировать дословно из `*_prompts_FULL.md` — не перефразировать.
2. **@image1 и @image2** брать из `assets/registry.md` — только строки со статусом `✅ approved`.
3. **Эмоция** для Человека — выбирать из Э1–Э6 в `chelovek_prompts_FULL.md`, подходящую к моменту сцены.
4. **Освещение** — выбирать из О1–О5 (Человек) или О1–О3 (Собака), соответствующее времени суток и драматургии.
5. **Видеопромпт** — описывать движение, а не статику: камера, тело персонажа, окружение.

## Условие завершения

После создания всех 8 файлов:
1. Обновить `production/status.md` — проставить `🔄 в работе` в колонку «Раскадровка» для каждой сцены
2. Сообщить пользователю: «Раскадровка готова. Требуется одобрение перед передачей агенту 02»
3. После одобрения пользователем — проставить `✅ одобрен` и передать управление агенту 02
