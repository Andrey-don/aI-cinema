# Оркестратор — Универсальный шаблон AI-кинопроизводства
> Главный документ многоагентной системы. Читать первым при старте любой новой сессии.
>
> **Текущий фильм:** «Костёр» (Jack London, 1902)
> **Папка фильма:** `films/film_01_kostyor/`

---

## Универсальность системы

Этот пайплайн предназначен для создания **любого короткого фильма** (9:16, Reels/Shorts/TikTok), не только «Костра».

**Чтобы запустить систему для нового фильма:**
1. Скопировать папку `films/film_01_kostyor/` → `films/film_NN_[название]/`
2. Очистить содержимое: `storyboard/scenes/`, `production/status.md`, `assets/registry.md`, `production/transitions.md`
3. Заменить данные персонажей в `characters/`
4. Запустить **Агент 00 — Девелопер** (`agents/00_developer.md`) для генерации идеи и синопсиса
5. Далее по схеме пайплайна ниже

**Шаблон для новых персонажей:** `_characters/_template/profile.md`

---

## Полная схема пайплайна

```
АГЕНТ 00 — Девелопер (для нового фильма)
  Читает: исходный материал / идею пользователя
  Пишет:  script/synopsis.md, CLAUDE.md фильма, characters/ (профили)
  Стоп:   ждёт одобрения концепции
        │
        ▼
ПОДГОТОВКА (пользователь + Syntx)
  └── Датасет Персонажа А → удаление фона → (опц.) обучение LoRA
  └── Датасет Персонажа Б → удаление фона → (опц.) обучение LoRA
        │
        ▼
АГЕНТ 01 — Раскадровщик
  Читает: script/ + characters/
  Пишет:  storyboard/scenes/scene_NN.md (по числу сцен)
  Стоп:   ждёт одобрения пользователя
        │
        ▼
АГЕНТ 02 — Генератор кадров
  Читает: storyboard/scenes/ + characters/ + registry.md
  Пишет:  assets/registry.md + production/status.md
  Стоп:   каждый кадр ждёт одобрения пользователя
        │
        ▼
АГЕНТ 03 — Видеограф
  Читает: registry.md (approved) + transitions.md + storyboard/scenes/
  Пишет:  video_prompts.md + transitions.md + registry.md (видео)
  Стоп:   каждый клип ждёт одобрения, last_frame фиксируется вручную
        │
        ▼
АГЕНТ 04 — Монтажёр
  Читает: registry.md (видео) + transitions.md + music_prompts.md
  Пишет:  production/edit_plan.md
  Стоп:   план одобряется пользователем → сборка в CapCut
```

## Файлы системы

| Файл | Роль |
|------|------|
| `production/status.md` | Единственная правда о статусе производства |
| `assets/registry.md` | Реестр всех ресурсов с путями и статусами |
| `production/transitions.md` | Протокол last-frame → start-image между сценами |
| `agents/00_developer.md` | Инструкция агента 00 — генерация идеи и синопсиса |
| `agents/01_storyboarder.md` | Инструкция агента 01 — раскадровка |
| `agents/02_frame_generator.md` | Инструкция агента 02 — генерация кадров |
| `agents/03_videographer.md` | Инструкция агента 03 — видеогенерация |
| `agents/04_editor.md` | Инструкция агента 04 — монтажный план |

---

## Главное правило

**Следующий агент не стартует, пока предыдущий не завершил работу и пользователь не дал команду «продолжай».**

Статус в `production/status.md` — единственный критерий готовности. Устная договорённость не считается.

## Как запустить агента

Скопировать в новый чат:

```
Проект: AI-Cinema, фильм [НАЗВАНИЕ].
Папка фильма: films/film_NN_[название]/
Запускаю: Агент [00 / 01 / 02 / 03 / 04]
Инструкция: agents/0N_[имя].md
Прочитай инструкцию, затем проверь production/status.md и начинай работу.
```
