# Оркестратор — «Костёр»
> Главный документ многоагентной системы. Читать первым при старте новой сессии.

---

## Схема пайплайна

```
ПОДГОТОВКА (пользователь)
  └── Датасет Человека 35 кадров → удаление фона → обучение LoRA
  └── Датасет Собаки 23 кадра   → удаление фона → обучение LoRA
        │
        ▼
АГЕНТ 01 — Раскадровщик
  Читает: script/ + characters/
  Пишет:  storyboard/scenes/scene_01.md … scene_08.md
  Стоп:   ждёт одобрения пользователя
        │
        ▼
АГЕНТ 02 — Генератор кадров
  Читает: storyboard/scenes/ + characters/ + registry.md
  Пишет:  assets/registry.md (SC01–SC08) + production/status.md
  Стоп:   каждый кадр ждёт одобрения пользователя
        │
        ▼
АГЕНТ 03 — Видеограф
  Читает: registry.md (approved) + transitions.md + storyboard/scenes/
  Пишет:  video_prompts.md + transitions.md + registry.md (VID01–VID08)
  Стоп:   каждый клип ждёт одобрения, last_frame фиксируется вручную
        │
        ▼
АГЕНТ 04 — Монтажёр
  Читает: registry.md (VID) + transitions.md + music_prompts.md
  Пишет:  production/edit_plan.md
  Стоп:   план монтажа одобряется пользователем → финальная сборка в CapCut
```

---

## Файлы системы

| Файл | Роль |
|------|------|
| `production/status.md` | Единственная правда о статусе производства |
| `assets/registry.md` | Реестр всех ресурсов с путями и статусами |
| `production/transitions.md` | Протокол last-frame → start-image между сценами |
| `agents/01_storyboarder.md` | Инструкция агента 01 |
| `agents/02_frame_generator.md` | Инструкция агента 02 |
| `agents/03_videographer.md` | Инструкция агента 03 |
| `agents/04_editor.md` | Инструкция агента 04 |

---

## Главное правило

**Следующий агент не стартует, пока предыдущий не завершил работу и пользователь не дал команду «продолжай».**

Статус в `production/status.md` — единственный критерий готовности. Устная договорённость не считается.

## Как запустить агента

Скопировать в новый чат:

```
Проект: AI-Cinema, фильм «Костёр».
Репозиторий: films/film_01_kostyor/
Запускаю: [Агент 01 / 02 / 03 / 04]
Инструкция агента: agents/0N_[имя].md
Прочитай инструкцию, затем проверь production/status.md и начинай работу.
```
