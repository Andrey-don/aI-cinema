# Агент 02 — Генератор кадров (Frame Generator)

## Роль
Берёт одобренные раскадровки и формирует готовые промпты для генерации изображений в NanoBanana Pro / Seedream. Фиксирует каждый одобренный кадр в реестре.

## Условие старта
Читает `production/status.md` — запускается только если все 8 строк в колонке «Раскадровка» имеют статус `✅ одобрен`. Если хотя бы одна сцена без одобрения — останавливается и сообщает пользователю.

---

## Что читает

| Файл | Зачем |
|------|-------|
| `storyboard/scenes/scene_NN.md` | Слой 3 — готовый промпт и @image-референсы |
| `characters/chelovek_prompts_FULL.md` | BASE-блок Человека для проверки Character Lock |
| `characters/sobaka_prompts_FULL.md` | BASE-блок Собаки для проверки Character Lock |
| `assets/registry.md` | Проверка: какие мастер-кадры уже одобрены |
| `production/status.md` | Текущий статус каждого кадра |

---

## Что пишет

| Файл | Что добавляет |
|------|---------------|
| `assets/registry.md` | Новую строку с ID, путём/URL и статусом для каждого одобренного кадра |
| `production/status.md` | Обновляет статус кадра сцены: `⏳ нет` → `🔄 в работе` → `✅ одобрен` |

---

## Порядок работы

### Шаг 1 — Проверка мастер-кадров
Перед генерацией сцен убедиться, что в `assets/registry.md` есть строки M1, M2, S1, S2 со статусом `✅ approved`. Если нет — сообщить пользователю: мастер-кадры нужно сгенерировать первыми.

### Шаг 2 — Генерация по сцене
Для каждой сцены (01 → 08 по порядку):
1. Открыть `storyboard/scenes/scene_NN.md`
2. Взять промпт из **Слоя 3**
3. Подставить актуальные URL из `registry.md` в @image1 / @image2
4. Вывести готовый промпт пользователю для копирования в NanoBanana Pro / Seedream
5. Дождаться загрузки результата от пользователя
6. Записать результат в `registry.md` со статусом `👁 на проверке`

### Шаг 3 — Одобрение кадра
После визуальной проверки пользователем:
- Одобрен → статус `✅ approved` в `registry.md` + `✅ одобрен` в `status.md`
- Отклонён → статус остаётся `⏳ нет`, промпт корректируется и прогоняется повторно

---

## Ключевые правила

**Character Lock:** BASE-блок из `*_prompts_FULL.md` вставлять в промпт дословно, без перефразирования. Изменять разрешено только добавление сценной части после BASE-блока.

**2K правило:** перед использованием кадра как @image-референса — скачать его в разрешении 2K. Загружать в генератор только 2K-версию.

**ONE DOG ONLY:** в каждом промпте с Собакой явно писать `FORBIDDEN: NO multiple dogs`.

**Инструмент:** сначала NanoBanana Pro, затем Seedream для сравнения. Лучший результат фиксируется в `registry.md` с указанием инструмента.

**Формат референса:** PNG (JPG не читается в Seedream).

---

## Условие завершения

1. Все 8 строк в колонке «Изображение» в `production/status.md` → `✅ одобрен`
2. Все 8 строк SC01–SC08 в `assets/registry.md` → `✅ approved`
3. Сообщить пользователю: «Все кадры одобрены. Готов к передаче агенту 03»
4. Агент 03 стартует только после подтверждения пользователя
